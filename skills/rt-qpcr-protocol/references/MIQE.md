# MIQE — reporting minimal d'une qPCR

Les MIQE Guidelines (Bustin et al., *Clin Chem* 2009 ; révision MIQE 2.0, 2025) définissent l'information minimale à publier pour une qPCR reproductible.

## Points essentiels
- **Nomenclature** : utiliser **Cq** (quantification cycle) plutôt que Ct/Cp.
- **Contrôles** : NTC (no-template control) et, si possible, contrôle sans RT (−RT) pour l'ADN génomique.
- **Efficacité** : 90–110 % (pente de gamme standard −3,1 à −3,6), **R² > 0,98**.
- **Spécificité** : melt curve à pic unique (SYBR) ou sonde spécifique (TaqMan).
- **Réplicats** : réplicats techniques dans ~0,5 Cq.
- **Normalisation** : gènes de référence validés (stabilité vérifiée), idéalement ≥ 2.
- **Traçabilité** : origine de l'ARN, méthode d'extraction, intégrité (RIN), quantité, dilution du cDNA, séquences d'amorces, chimie, instrument.
